# Breast Cancer Detection using Machine Learning

## Overview

Breast cancer remains one of the most prevalent and life-threatening diseases worldwide. Traditional diagnostic methods are often costly and time-consuming. This project leverages Machine Learning (ML) techniques to provide a faster and more accurate diagnosis of breast cancer using the Wisconsin Breast Cancer dataset.

## Abstract

Machine learning algorithms such as Neural Networks, k-Nearest Neighbors (k-NN), Support Vector Machines (SVM), and Random Forest were explored for breast cancer detection. The models were trained and tested using various ratios, and evaluated based on metrics like **Accuracy**, **Mean Squared Error (MSE)**, and **Mean Absolute Error (MAE)**. 

### Key Findings:
- **Neural Network** achieved the highest accuracy of **98%**.
- It also recorded a very low **MSE of 1%** and **MAE of 1%**.
- This demonstrates the potential of ML in early and accurate diagnosis, contributing to improved patient outcomes.

## Dataset

- **Name:** Wisconsin Breast Cancer Dataset
- **Source:** UCI Machine Learning Repository
- The dataset includes features computed from digitized images of breast mass and their corresponding labels (benign or malignant).

## Models Used

- Neural Network
- k-Nearest Neighbors (k-NN)
- Support Vector Machine (SVM)
- Random Forest

## Evaluation Metrics

- Accuracy
- Mean Squared Error (MSE)
- Mean Absolute Error (MAE)

## Conclusion

Machine learning shows great promise in the field of medical diagnosis. With high accuracy and low error rates, these models can supplement traditional diagnostic methods and assist healthcare professionals in early disease detection.
